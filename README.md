Assignment One: Clinic Appointment System
This is a Java console program for clinic appointment management.

Features
1.Create new patient appointments
2. Check appointment conflict (doctor time duplicate check)
3. Search appointment by ID
4.Cancel existing appointment
5. Multiple types of health professionals: General Practitioner, Specialist, Nurse, Dietitian

File Structure
1. HealthProfessional.java: Abstract parent class
2. GeneralPractitioner.java, Specialist.java, Nurse.java, Dietitian.java: Subclasses
3. Patient.java: Patient information
4. Appointment.java: Appointment record
5. AppointmentManager.java: Manage all appointments
6. AssignmentOne.java: Main class, user menu,test

How to run
Run the "AssignmentOne.java" file in VS Code or other Java IDE.
